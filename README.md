
## 🧮 Temas de cálculo que ilustra

| Módulo | Conceptos matemáticos |
|---|---|
| EBM | EDOs autónomas, puntos de equilibrio, estabilidad lineal, bifurcaciones |
| CO₂ | EDO lineal no homogénea, integración por factor integrante, retroalimentación |
| Lorenz | Sistemas de EDOs, integración numérica (RK45), sensibilidad a condiciones iniciales |
| ENSO | EDOs estocásticas, ecuaciones con retardo, método de Euler–Maruyama, Monte Carlo |
